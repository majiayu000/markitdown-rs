markitdown-rs

Microsoft's markitdown as one Rust binary: convert PDF, Word, PowerPoint, Excel, HTML, EPUB, Outlook and web pages to Markdown for LLMs and RAG pipelines. Same output, byte for byte. No Python. 23–112× faster.

# Markdown

Plain text markup language

Why markitdown-rs

Drop-in

Same command, same flags, same Markdown. Every test file is checked byte for byte against Python markitdown 0.1.9.

One small binary

A 4.5 MB binary instead of a 328 MB Python environment with pdfminer, pandas, mammoth, magika and onnxruntime.

Fast

23–112× faster end to end; a 100-page PDF in 0.18 s instead of 5.9 s.

Every local format

PDF, DOCX, PPTX, XLSX, XLS, HTML, EPUB, Outlook MSG, CSV, ZIP, RSS, Jupyter, text, images and audio metadata, plus http(s) URLs, Wikipedia and YouTube pages.
