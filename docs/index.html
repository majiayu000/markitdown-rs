markitdown-rs

Microsoft's markitdown rewritten in Rust: convert PDF, Word, PowerPoint, Excel, HTML, EPUB, Outlook and web pages to Markdown for LLMs and RAG pipelines. The same command and the same Markdown, byte for byte, without a Python environment. From the command line it is usually hundreds of times faster.

Why markitdown-rs

Drop-in

Same command, same flags, same Markdown. 401 of 406 test files are byte-identical to Python markitdown 0.1.9, checked on every commit.

One small binary

A 4.5 MB binary instead of a 328 MB Python environment with pdfminer, pandas, mammoth, magika and onnxruntime.

Fast

Median 408× faster from the command line on 231 real-world files, about 16× on the largest; 4–48× in process. A quarter to a sixth of the memory.

Every format

PDF, DOCX, PPTX, XLSX, XLS, HTML, EPUB, Outlook MSG, CSV, ZIP, RSS, Jupyter, text, images and audio metadata, plus URLs, Wikipedia pages and YouTube pages with transcripts.

Python package

The Python package markitdown-rs has markitdown's API on the same Rust converters. It installs the markitdown module, so existing code keeps from markitdown import MarkItDown; install it instead of Microsoft's package, not next to it. It is not on PyPI yet: build the wheel with maturin from crates/markitdown-py.

>>> from markitdown import MarkItDown
>>> MarkItDown().convert("report.pdf").markdown
  • The full markitdown command. The package installs markitdown 0.1.9's own markitdown command (and python -m markitdown) with all of its flags: -p and --list-plugins, -d/-e, --use-cu. The Rust binary is the fast path; this one is the full-parity path.
  • Plugins. markitdown plugins load through the same entry points; markitdown-ocr gives the same output as with markitdown. Plugins depend on Microsoft's package, so install them without it: pip install 'markitdown-rs[ocr]', then pip install --no-deps markitdown-ocr.
  • The rest of markitdown's options. Custom converters, style_map (through mammoth, as markitdown does), LLM image and slide captions (llm_client), audio transcription, YouTube transcripts, requests_session, exiftool_path and the Azure converters.

MCP server

markitdown mcp serves the same convert_to_markdown tool as markitdown-mcp to AI agents over stdio; markitdown mcp --http serves it over Streamable HTTP and SSE.

$ claude mcp add markitdown -- markitdown mcp
$ markitdown mcp --http --port 3001

FAQ

Is markitdown-rs a drop-in replacement for markitdown?

For conversions, yes: the same command, the same flags and the same Markdown. 401 of the 406 test files, and all 232 real-world files both convert in an independent check, come out byte for byte the same as markitdown 0.1.9; the 5 documented differences are rare PDF layout ties and charset guesses. The Python package keeps the same import, from markitdown import MarkItDown, and the same API.

Does markitdown-rs need Python?

No. The markitdown binary is a single 4.5 MB file with no runtime dependencies. Python is needed only for the optional Python package, which you install instead of Microsoft's markitdown package.

How much faster is markitdown-rs than markitdown?

From the command line, usually hundreds of times faster: a median of 408× over 231 real-world files (14.5× to 1,660×), and about 16× on the largest PDFs and spreadsheets. In process, the Python package is 4.7× to 48× faster. It answers --version in 4 ms; Python markitdown takes 1.9 s to start.

Does markitdown-rs support plugins, OCR and Azure?

In the Python package, yes. markitdown plugins load through the same entry points, and the markitdown-ocr plugin gives the same output as with markitdown (install it with pip install --no-deps markitdown-ocr). LLM image captions, audio transcription and style_map work too. Azure Document Intelligence and Content Understanding run markitdown's own converter code, tested with mocked clients only: they have not been run against a live Azure account. The Rust binary does none of these.

Can I use markitdown-rs as an MCP server?

Yes. markitdown mcp serves the same convert_to_markdown tool as markitdown-mcp over stdio, and markitdown mcp --http serves it over Streamable HTTP and SSE on 127.0.0.1:3001. For Claude Code: claude mcp add markitdown -- markitdown mcp.
